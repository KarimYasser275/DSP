# Project Descriptions for CV

## Embedded Linux Assignments (AELD Course)
Completed a comprehensive series of assignments covering advanced embedded Linux development and system programming fundamentals. Developed kernel-level programs and device drivers in C, implementing core concepts including process management, inter-process communication, and system calls. Created shell scripts for system automation and administration tasks. Gained proficiency with build systems including CMake and Makefiles for multi-platform compilation and project organization.

## K-RTOS
Designed and implemented a fully functional real-time operating system from scratch in C. Developed core OS components including task scheduling, context switching, memory management, and inter-process communication mechanisms. Optimized kernel-level functionality for efficient embedded system execution with minimal resource overhead.

## Digital Signal Processing (DSP)
Implemented advanced digital signal processing algorithms and applications in C. Developed solutions for audio analysis, filtering, and real-time signal processing. Demonstrated proficiency in numerical computing, algorithm optimization, and signal manipulation techniques.

## BitBake Build System (Assignment 6)
Configured and optimized embedded Linux build automation using BitBake and shell scripting. Developed and maintained build recipes for cross-compilation environments, automated package management workflows, and streamlined embedded system development processes.
